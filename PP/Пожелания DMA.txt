 Мои пожелания по распределению DMA:
USART1 - RX - прерывания
USART1 - TX - DMA
USART2 (1-Wire DS18B20) - DMA 
USART3 (SDI-12 / RS-485) - RX - прерывания
USART3 (SDI-12 / RS-485) - TX - DMA 
SPI - Для AD7799 — достаточно прерывания. Для Flash — в момент чтения логов можно приостановить измерения. По этому оставляем прерывания.
I2C1 (EEPROM, RTC, LTC4151, LSM303) - прерывания
ADC1 - прерывания
